### 3. Responsive Layout Strategy (320px Mobile-First)

* **Viewport Bounds:** Designed and tested for viewport widths from `320px` (iPhone SE, small Androids) to `3840px` (4K Ultrawide).
* **Grid Breakpoints:**
  * `< 1024px (Mobile & Tablet):` Single column stacked vertical layout (`grid-cols-1`).
  * `≥ 1024px (Desktop):` 3-Column Studio layout (`grid-cols-12`: 4 cols Story, 4 cols Scenes, 4 cols Preview/Publish).
* **9:16 Video Player Adaptation:**
  * Container uses responsive sizing: `w-full max-w-[240px] sm:max-w-[270px] aspect-[9/16] mx-auto`.
  * Guarantees zero horizontal clipping on 320px screens (allowing 24px total outer padding).
* **Horizontal Scrollable Navigation:**
  * Navigation tabs use `overflow-x-auto no-scrollbar` to allow smooth finger scrolling on small screens.

---

### 4. Component Hierarchy & Reusability

All UI components are modularized under `src/components/common/` to avoid code duplication:
* **`GlassPanel`**: Translucent container with standard and glowing states.
* **`CosmicButton`**: Pill-shaped action button with gradient fills, size variants (`sm`, `md`, `lg`), and integrated loading state.
* **`Badge`**: Status indicators with semantic variants (`emerald`, `purple`, `yellow`, `red`, `dark`).
* **`FormControls`**: Accessible, custom-styled `CosmicSelect`, `CosmicTextarea`, and `CosmicLabel`.
* **`SocialIcons`**: Scalable SVG icons for YouTube, Instagram, Facebook, and TikTok.
