# 13. Third-Party API & Service Integrations

---

### 1. Social Media Publishing Integrations

#### 1.1 YouTube Data API v3
* **Primary Scope:** `https://www.googleapis.com/auth/youtube.upload`
* **Workflow:**
  1. Authenticates channel owner via Google OAuth 2.0.
  2. Obtains permanent `refresh_token` stored securely in SQLite database.
  3. Uploads 9:16 vertical MP4 video via resumable upload endpoint:
     `POST https://www.googleapis.com/upload/youtube/v3/videos?part=snippet,status`
  4. Appends `#Shorts` in title and description to enter the official Shorts algorithmic shelf.

#### 1.2 Meta Graph API (Instagram Reels)
* **Primary Scope:** `instagram_content_publish`, `pages_show_list`
* **Workflow:**
  1. Step 1 (Create Reel Container):
     `POST https://graph.facebook.com/v19.0/{ig_user_id}/media`
     Parameters: `media_type=REELS`, `video_url=...`, `caption=...`
  2. Step 2 (Poll Status): Checks container state until `status_code="FINISHED"`.
  3. Step 3 (Publish Container):
     `POST https://graph.facebook.com/v19.0/{ig_user_id}/media_publish`

#### 1.3 Meta Graph API (Facebook Page Reels)
* **Primary Scope:** `pages_manage_posts`, `publish_video`
* **Workflow:** Uses the Facebook Page Video API:
  `POST https://graph.facebook.com/v19.0/{page_id}/video_reels`
  Shares authentication tokens seamlessly with the Instagram connection.

#### 1.4 TikTok Content Posting API
* **Primary Scope:** `video.upload`, `video.publish`
* **Endpoint:** `https://open.tiktokapis.com/v2/post/publish/video/init/`
* **Modes:** Direct Scheduled Post or Creator Inbox draft dispatch.

### 2. Media & AI Generation Integrations

#### 2.1 Microsoft Edge-TTS (Zero Cost Neural Speech)
* **Protocol:** WebSocket streaming direct to Microsoft's cloud neural synthesis service.
* **Cost:** **$0.00 / month (Unlimited).**
* **Languages:**
  * Tamil: `ta-IN-ValluvarNeural`, `ta-IN-PallaviNeural`
  * English: `en-US-ChristopherNeural`, `en-US-GuyNeural`, `en-US-AriaNeural`
  * Hindi: `hi-IN-MadhurNeural`, `hi-IN-SwaraNeural`

#### 2.2 Pollinations.ai (Flux.1 Model)
* **Endpoint:** `https://image.pollinations.ai/prompt/{prompt}?width=720&height=1280&model=flux&nologo=true`
* **Cost:** Free generative AI image synthesis with no API key requirement.
* **Aspect Ratio:** Native 9:16 vertical generation (720x1280).

#### 2.3 Pexels Video API
* **Endpoint:** `https://api.pexels.com/videos/search?query={keyword}&orientation=portrait`
* **License:** Royalty-free HD vertical stock video for commercial use.
