# 5. REST API Specification

## Protocol: HTTP/1.1 & HTTP/2  
**Base URL:** `http://localhost:8000`  
**Interactive Docs (Swagger UI):** `http://localhost:8000/docs`  
**Alternative Docs (ReDoc):** `http://localhost:8000/redoc`  

---

### 1. Authentication Endpoints

#### 1.1 Register New User
* **Method:** `POST /api/auth/register`
* **Request Body:**
  ```json
  {
    "email": "creator@example.com",
    "password": "secure_password_123",
    "full_name": "Pro Creator"
  }
  ```
* **Success Response (200 OK):**
  ```json
  {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "bearer",
    "user": {
      "id": 1,
      "email": "creator@example.com",
      "full_name": "Pro Creator",
      "is_active": true
    }
  }
  ```

#### 1.2 Login User
* **Method:** `POST /api/auth/login`
* **Request Body:**
  ```json
  {
    "email": "creator@example.com",
    "password": "secure_password_123"
  }
  ```
* **Success Response (200 OK):** Returns signed JWT access token and user profile object.

#### 1.3 Get Current User Profile
* **Method:** `GET /api/auth/me`
* **Headers:** `Authorization: Bearer <JWT_ACCESS_TOKEN>`
* **Success Response (200 OK):** Current authenticated user data.

### 2. Video Engine Endpoints

#### 2.1 Get Supported Voices
* **Method:** `GET /api/voices`
* **Response (200 OK):** Array of available neural voice models (Tamil, English, Hindi).

#### 2.2 Generate Story Blueprint
* **Method:** `POST /api/script/blueprint`
* **Request Body:**
  ```json
  {
    "topic": "The poor strawberry's last wish",
    "niche": "emotional_drama",
    "language": "Tamil"
  }
  ```
* **Response (200 OK):**
  ```json
  {
    "title": "The Strawberry's Last Wish - ஒரு உணர்ச்சிகரமான கதை",
    "language": "Tamil",
    "voice_id": "ta-IN-ValluvarNeural",
    "full_narration": "இந்த ஒரு ஆசை அவனுடைய மொத்த வாழ்க்கையையும் இப்படி மாற்றிவிடும்...",
    "scenes": [
      {
        "scene_id": 1,
        "duration_sec": 4,
        "visual_prompt": "3D cute Pixar style emotional animated strawberry...",
        "subtitles": "இந்த ஒரு ஆசை அவனுடைய வாழ்க்கையையே மாற்றியது..."
      }
    ],
    "recommended_hashtags": ["#TamilReels", "#Shorts"]
  }
  ```

#### 2.3 Synthesize Voice & Subtitles
* **Method:** `POST /api/voice/synthesize`
* **Request Body:**
  ```json
  {
    "text": "வணக்கம்! இது தானியங்கி வீடியோ தளம்.",
    "voice": "ta-IN-ValluvarNeural",
    "filename": "speech_sample.mp3"
  }
  ```
* **Response (200 OK):**
  ```json
  {
    "audio_path": "storage/audio/speech_sample.mp3",
    "srt_path": "storage/audio/speech_sample.srt",
    "srt_content": "1\n00:00:00,100 --> 00:00:02,300\nவணக்கம்!\n\n",
    "url": "/storage/audio/speech_sample.mp3"
  }
  ```

#### 2.4 Generate Scene Visual
* **Method:** `POST /api/media/generate-scene`
* **Request Body:**
  ```json
  {
    "prompt": "3D Pixar style cute boy holding glowing star",
    "scene_id": 1
  }
  ```
* **Response (200 OK):** Returns generated 720x1280 image URL.

#### 2.5 Render 9:16 Reel
* **Method:** `POST /api/render/video`
* **Request Body:**
  ```json
  {
    "scene_images": ["storage/images/scene_1.jpg", "storage/images/scene_2.jpg"],
    "audio_path": "storage/audio/speech.mp3",
    "output_filename": "final_reel.mp4"
  }
  ```
* **Response (200 OK):**
  ```json
  {
    "status": "success",
    "video_path": "storage/output/final_reel.mp4",
    "url": "/storage/output/final_reel.mp4"
  }
  ```

### 3. Social Dispatcher Endpoints

#### 3.1 List Connected Accounts
* **Method:** `GET /api/accounts`
* **Response (200 OK):** Connected YouTube, Instagram, Facebook, and TikTok accounts.

#### 3.2 Publish Video to Accounts
* **Method:** `POST /api/social/publish`
* **Request Body:**
  ```json
  {
    "account_ids": ["yt_shorts_main", "ig_reels_kids"],
    "video_path": "storage/output/final_reel.mp4",
    "title": "The Strawberry's Last Wish #Shorts",
    "description": "Emotional drama story...",
    "tags": ["#TamilReels", "#AIStory"]
  }
  ```
* **Response (200 OK):** Batch publishing status per target platform.
