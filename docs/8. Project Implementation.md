### 2. Architectural Rules & Modularity

1. **Import-Only `src/app/page.tsx`:** The root page file contains zero business logic, zero inline styles, and zero massive DOM trees. It acts strictly as an orchestrator importing views from `src/components/`.
2. **Zero Hardcoded Data in Components:** No string literals, mock accounts, voice arrays, or prompt templates are embedded directly inside components. All static constants reside in [`src/components/hardcodedata/index.ts`](file:///d:/Work_Space/products/Ai%20Content%20Vedio/frontend/src/components/hardcodedata/index.ts).
3. **Common UI Library:** All buttons, panels, badges, form elements, and brand icons are abstracted into [`src/components/common/`](file:///d:/Work_Space/products/Ai%20Content%20Vedio/frontend/src/components/common) for uniform styling and zero code duplication.
4. **Mobile First down to 320px:** Strict usage of `w-full max-w-full overflow-hidden`, responsive aspect ratios, and horizontal scrollable containers ensures perfect rendering on small mobile screens.
