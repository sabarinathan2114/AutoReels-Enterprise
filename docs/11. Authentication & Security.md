# 11. Authentication & Security Specification

---

### 1. Password Hashing Architecture

User passwords are encrypted before database insertion using **native `bcrypt`** with **12 salt rounds**:

```python
import bcrypt

class AuthService:
    @staticmethod
    def hash_password(plain_password: str) -> str:
        salt = bcrypt.gensalt(rounds=12)
        hashed = bcrypt.hashpw(plain_password.encode("utf-8"), salt)
        return hashed.decode("utf-8")

    @staticmethod
    def verify_password(plain_password: str, hashed_password: str) -> bool:
        return bcrypt.checkpw(
            plain_password.encode("utf-8"),
            hashed_password.encode("utf-8")
        )
```

#### Security Properties:
* **Salt Randomization:** Every user receives an independent cryptographic salt.
* **Brute-Force Resistance:** 12 rounds of key derivation provide high computational work factors, preventing rainbow table attacks.
* **Zero Plaintext Storage:** Passwords are never logged, cached, or written to disk in plain text.

### 2. JWT Token Issuance & Signature

* **Algorithm:** HMAC-SHA256 (`HS256`).
* **Expiration:** 7 Days (`60 * 24 * 7` minutes).
* **Token Payload Structure:**
  ```json
  {
    "sub": "creator@example.com",
    "user_id": 1,
    "exp": 1794902400
  }
  ```
* **Endpoint Protection:** Protected endpoints enforce token presence via FastAPI's `OAuth2PasswordBearer` dependency:
  ```python
  def get_current_user(token: str = Depends(oauth2_scheme), db: Session = Depends(get_db)) -> User: ...
  ```

---

### 3. Client-Side Storage: `sessionStorage`

As specified by architectural requirements, the client application persists credentials in **`sessionStorage`** rather than `localStorage`:
* **Advantage:** Tokens automatically purge when the browser tab/session closes, protecting shared creator workstations from unauthorized access.
* **Storage Helper:** [`frontend/src/components/common/authStorage.ts`](file:///d:/Work_Space/products/Ai%20Content%20Vedio/frontend/src/components/common/authStorage.ts)
  * `saveSession(token, user)`: Writes `az_jwt_token` and `az_user` to `sessionStorage`.
  * `clearSession()`: Clears credentials on user logout.

### 4. CORS & API Security Policies
* **Origin Whitelisting:** Configured in `backend/app/main.py` to allow cross-origin requests from the Next.js frontend port.
* **Input Validation:** All payloads are validated using Pydantic v2 schemas (`EmailStr`, string length constraints, type enforcement).
