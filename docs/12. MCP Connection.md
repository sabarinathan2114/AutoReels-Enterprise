# 12. Model Context Protocol (MCP) Connection Specification

---

### 1. Overview of MCP in the Video Pipeline

The **Model Context Protocol (MCP)** provides an open, standardized framework to connect LLM director agents to external tools, data sources, and video manipulation services. 

Through MCP, our AI Director Agent interacts directly with system resources (file systems, media scrapers, TTS engines, and social media dispatchers) without requiring custom API glues.

```mermaid
flowchart LR
    LLM[LLM Director Agent\n(Claude / Gemini / GPT-4o)] 
    MCPServer[FastAPI MCP Server Gateway]

    subgraph Tools ["MCP Exposed Tool Handlers"]
        Tool1[mcp://tools/fetch_regional_trends]
        Tool2[mcp://tools/synthesize_voice]
        Tool3[mcp://tools/generate_visual_prompt]
        Tool4[mcp://tools/render_reel]
        Tool5[mcp://tools/dispatch_social]
    end

    LLM <-->|JSON-RPC 2.0 / SSE| MCPServer
    MCPServer --> Tools
```

### 2. Standard Tool Definitions (MCP Schema)

#### 2.1 `fetch_regional_trends`
* **Description:** Ingests breakout trends from Google Trends RSS, Reddit, or local news for a specified domain and country.
* **Input Schema:**
  ```json
  {
    "type": "object",
    "properties": {
      "region": { "type": "string", "description": "ISO country code, e.g. IN, US" },
      "category": { "type": "string", "enum": ["tech", "geopolitics", "entertainment", "general"] }
    },
    "required": ["region", "category"]
  }
  ```

#### 2.2 `synthesize_neural_voice`
* **Description:** Generates audio speech file and word-level subtitle alignment from narration script.
* **Input Schema:**
  ```json
  {
    "type": "object",
    "properties": {
      "text": { "type": "string" },
      "voice_id": { "type": "string" }
    },
    "required": ["text", "voice_id"]
  }
  ```

#### 2.3 `render_916_reel`
* **Description:** Submits scene asset arrays and audio file to the local FFmpeg compositing service to render final 1080x1920 MP4 video.
* **Input Schema:**
  ```json
  {
    "type": "object",
    "properties": {
      "scenes": { "type": "array", "items": { "type": "string" } },
      "audio_file": { "type": "string" },
      "caption_style": { "type": "string" }
    },
    "required": ["scenes", "audio_file"]
  }
  ```

### 3. MCP Server Configuration (`mcp_config.json`)

To register the studio's MCP server with external agent hosts or IDEs:

```json
{
  "mcpServers": {
    "reels-studio": {
      "command": "python",
      "args": ["-m", "backend.app.mcp_server"],
      "env": {
        "PORT": "8000",
        "DATABASE_URL": "sqlite:///./studio.db"
      }
    }
  }
}
```
