# 1. Product Requirements Document (PRD)

## Project Title: AutoReels Enterprise Master Build v2.0 (Free-First)
**Document Version:** 2.0.0 (Supersedes v1.0 per Master Build Specification v2.0)  
**Core Strategy:** Free-First Zero Cash Spend Production Pipeline with Plan Tiers (Free, A, B, C)  
**Target Viewports:** Strictly Responsive from 320px (Mobile) to 4K Displays  

---

### 1. Executive Summary & Strategic Positioning
AutoReels Enterprise v2.0 delivers an autonomous short-form vertical video (9:16) engine that produces viral video content with **zero cash spend** on generation. 

By eliminating reliance on expensive paid APIs ($50–$150/mo) and fragmented tab-switching (ChatGPT $\to$ ElevenLabs $\to$ Midjourney $\to$ CapCut $\to$ Social Apps), AutoReels consolidates trend discovery, scriptwriting, neural voice synthesis, visual generation, kinetic subtitle assembly, and multi-channel publishing into a single, high-performance web studio.

---

### 2. The 7 Killer Features (Ranked by Value per Effort)

1. **The "Zero-Input" Auto-Pilot:** Pick a niche/channel $\to$ Engine identifies trending topics, scripts a viral story, synthesizes voice, renders video, and schedules dispatch.
2. **Director Mode:** Real-time line-by-line script and scene editor with instant live audio synthesis and 1-click AI visual regeneration.
3. **Dynamic Kinetic Captions:** High-contrast, bouncing karaoke subtitles with millisecond word timestamps rendered via ASS subtitle tags in FFmpeg.
4. **Speech Ducking & Audio Normalization:** Automatic -18dB background score attenuation during voiceover activity.
5. **Universal Social Media Dispatcher:** Cross-posting to YouTube Shorts, Instagram Reels, Facebook Reels, and TikTok via the pluggable `BaseSocialAdapter`.
6. **Human-in-the-Loop Review-First Gate:** 1-Click approval queue preventing hallucinations or copyright strikes before public broadcast.
7. **Viral Feedback Loop & Plan Matrix:** Performance tracking and tiered plans managed via Super Admin.

### 4. Hardware Independence & Zero Cost Constraints
* **No Dedicated GPU Required:** Designed to run 100% locally on standard laptops (e.g. Intel HD Graphics 620) using CPU-optimized pipelines.
* **Open Source Free Media Engine:**
  * Scripting: Local LLMs / Free API Tiers (Gemini / Groq)
  * Voice: Microsoft Edge-TTS / Kokoro-82M (Unlimited, Zero Cost)
  * Visuals: Pexels Royalty-Free Vertical Video + Pollinations Flux.1 Schnell AI
  * Compositor: Local FFmpeg with zoompan, crossfades, and libass subtitle burning
