# 9. Local Development & Environment Setup Guide

---

### 1. Prerequisites & Environment Requirements

* **Operating System:** Windows 10/11, macOS, or Linux.
* **Python Runtime:** Python **3.12.x** (verified with Python 3.12.10).
* **Node.js Runtime:** Node.js **v20+** or **v24+** (verified with Node v24.15.0) and npm 11+.
* **Hardware:** Any modern dual-core or quad-core processor with 8GB RAM. Dedicated GPU is **not required** (runs on integrated Intel HD graphics).

---

### 2. Backend Installation (FastAPI)

1. Open PowerShell or Terminal and navigate to the project root:
   ```bash
   cd "d:\Work_Space\products\Ai Content Vedio"
   ```

2. Install Python dependencies:
   ```bash
   pip install -r backend/requirements.txt
   ```
   *Required packages installed:*
   * `fastapi>=0.110.0`
   * `uvicorn[standard]>=0.28.0`
   * `pydantic>=2.6.0`
   * `edge-tts>=6.1.12`
   * `sqlalchemy>=2.0.0`
   * `pyjwt>=2.8.0`
   * `bcrypt>=4.1.0`
   * `httpx>=0.27.0`
   * `imageio-ffmpeg>=0.4.9` (Provides bundled FFmpeg binary automatically)

3. Start the FastAPI development server:
   ```bash
   cd backend
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
   *The SQLite database file `backend/studio.db` is initialized automatically on first startup.*

---

### 3. Frontend Installation (Next.js)

1. In a separate terminal, navigate to the `frontend` folder:
   ```bash
   cd "d:\Work_Space\products\Ai Content Vedio\frontend"
   ```

2. Install npm dependencies:
   ```bash
   npm install
   ```

3. Start the Next.js development server:
   ```bash
   npm run dev
   ```
   *Application will be live at [http://localhost:3000](http://localhost:3000)*

---

### 4. 1-Click Startup Script (Windows)

For daily convenience, simply double-click or execute the included batch file:
```cmd
.\run_app.bat
```
This automatically launches both the FastAPI backend and Next.js frontend in separate terminal windows with hot reloading enabled.
