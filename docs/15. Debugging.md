### 1. Common Diagnostics & Troubleshooting

#### Issue 1: `ffmpeg: command not found` on Windows
* **Symptom:** `RenderService` throws an executable lookup error when attempting to stitch video files.
* **Root Cause:** FFmpeg is not installed in the Windows system `PATH`.
* **Fix Applied:** Our engine uses `imageio_ffmpeg.get_ffmpeg_exe()` to resolve the bundled, verified FFmpeg binary automatically with zero PATH dependencies:
  ```python
  import imageio_ffmpeg
  ffmpeg_exe = imageio_ffmpeg.get_ffmpeg_exe()
  ```

#### Issue 2: Edge-TTS Connection Reset or Rate Limit
* **Symptom:** `aiohttp.ClientConnectorError` during high-frequency speech requests.
* **Fix:** 
  1. Add retry backoff in `VoiceService`:
     ```python
     for attempt in range(3):
         try:
             await communicate.save(output_audio_path)
             break
         except Exception:
             await asyncio.sleep(1.5)
     ```
  2. Verify that network traffic allows outbound WebSocket connections to `speech.platform.bing.com:443`.

#### Issue 3: Next.js Missing Brand Icons in `lucide-react`
* **Symptom:** `Export Youtube/Instagram doesn't exist in target module` during Turbopack compilation.
* **Root Cause:** Brand icons were removed from recent versions of `lucide-react` due to trademark policies.
* **Fix Applied:** Created custom scalable inline SVG components inside [`src/components/common/SocialIcons.tsx`](file:///d:/Work_Space/products/Ai%20Content%20Vedio/frontend/src/components/common/SocialIcons.tsx).

#### Issue 4: Next.js Layout Overflow on Mobile (320px)
* **Symptom:** Horizontal scrollbar appears on narrow smartphone viewports.
* **Fix Applied:**
  * Enforce `w-full max-w-full overflow-hidden` on parent wrappers.
  * Constrain video player preview with `aspect-[9/16]` and responsive max-width: `max-w-[240px] sm:max-w-[270px]`.
  * Enable horizontal finger scrolling for nav pills: `overflow-x-auto no-scrollbar`.

#### Issue 5: JWT Token Expiration or Invalid Token (401 Unauthorized)
* **Symptom:** Protected endpoints return `Could not validate credentials or token expired`.
* **Fix:** The frontend automatically detects 401 responses, invokes `AuthStorage.clearSession()`, and opens the `AuthModal` dialog for fresh authentication.

### 2. Log Files & Inspection Points

* **FastAPI Server Logs:** Standard output stream in the terminal window launched by `run_app.bat`.
* **SQLite Database:** Inspect tables directly using SQLite CLI or VS Code SQLite Viewer extension:
  ```bash
  sqlite3 backend/studio.db ".tables"
  sqlite3 backend/studio.db "SELECT id, email, created_at FROM users;"
  ```
* **Rendered Output Directory:** Inspect generated MP4 files in [`backend/storage/output/`](file:///d:/Work_Space/products/Ai%20Content%20Vedio/backend/storage/output).
